# Soundbox — менеджер прослушанных музыкальных альбомов

Веб-приложение на **ASP.NET Core MVC (.NET 10)**: личная фонотека в стиле bandcamp.
Данные хранятся в **JSON-файлах** (без базы данных), у каждого пользователя — своя библиотека.

## Возможности

- **Публичная главная (лендинг)** на `/` — хиро + витрина альбомов, видна без входа.
- Сетка альбомов с обложкой, названием, исполнителем, жанрами и 5-звёздочной оценкой (с половинами).
- **Блок статистики**: всего / прослушано / в планах / избранное / средняя оценка / топ-жанры.
- Поиск по названию/исполнителю, фильтр по жанру, сортировка (алфавит, дата, исполнитель, оценка, жанр).
- Вкладки-библиотека: все / прослушанные / в планах / избранное.
- **Детальный просмотр** альбома в модальном окне → кнопка «Редактировать» открывает форму;
  смена статуса, избранное, удаление.
- **Автозагрузка из iTunes**: при добавлении альбома можно найти его в каталоге iTunes — название,
  исполнитель, год, жанр и обложка (600×600) подтянутся автоматически. Можно и вручную (ссылкой).
- Кнопка «+» снизу справа — добавление альбома.
- Регистрация и вход по имени и паролю (пароли хранятся как PBKDF2-хеш с солью).

## Запуск

```bash
dotnet run --project AlbumManager --launch-profile http
```

Откройте http://localhost:5077

При первом запуске создаётся демо-аккаунт с примерами альбомов:

- **Логин:** `demo`
- **Пароль:** `demo`

## Где хранятся данные

Каталог `AlbumManager/App_Data/` (создаётся автоматически, в гите игнорируется):

- `users.json` — пользователи (имя + хеш пароля);
- `albums/{userId}.json` — альбомы конкретного пользователя.

Чтобы сбросить всё (включая демо-данные) — удалите папку `App_Data` и перезапустите приложение.

## Структура

```
kursach/
├─ AlbumManager.sln            ← решение (открывать в Visual Studio)
└─ AlbumManager/               ← проект
   ├─ Controllers/   HomeController (лендинг), AccountController, AlbumsController
   ├─ Models/        User, Album, AlbumStatus, AlbumQuery (+ модель статистики)
   ├─ Services/      JsonStore, UserStore, AlbumStore, PasswordHasher, DataSeeder, MusicSearchService (iTunes)
   ├─ Helpers/       StarRenderer (отрисовка звёзд)
   ├─ Views/Home/    Index — лендинг (хиро + витрина)
   ├─ Views/Albums/  Index (сетка/фильтры/статистика), _AlbumDetail (просмотр), _AlbumForm (форма+поиск)
   └─ wwwroot/       css/site.css (тёмная тема), js/site.js (модалки, звёзды, iTunes-поиск)
```

## Внешнее API

Поиск альбомов — бесплатный **iTunes Search API** (без ключа). Запросы идут с сервера
(`MusicSearchService`), поэтому CORS не задействован. При недоступности сети поиск вернёт пустой
список, останется ручной ввод ссылки на обложку.
